# Introduction
Yahboom ESP32-S3 core board is a high-performance development platform specifically designed for AI voice interaction, edge AI computing, and smart hardware development. It is powered by the ESP32-S3-WROOM-1-N16R8 chip, integrating 16MB Flash and 8MB PSRAM, and supports dual-mode wireless communication via 2.4GHz WiFi and BT LE 5.0, providing stable and efficient wireless connectivity for AI applications. The core board incorporates the ESP32-S3 vector instruction set and AI hardware acceleration capabilities, easily running applications such as speech recognition, voice wake-up, offline voice control, and edge AI inference. It also supports mainstream development environments such as AR, ESP-IDF, and MicroPython, making it suitable for AI developers, makers, university labs, robotics education, and research projects. It is an ideal development platform for learning artificial intelligence, the Internet of Things, and edge computing.
